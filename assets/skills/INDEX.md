# Agent knowledge

The production agent reads these skills to drive the pipeline. They are the
editable "how" of OpenMontage Studio — change them to change how the agent works,
no Dart edits required. Intelligence lives in the knowledge; the code is plumbing.

- `production.md` — the agent's role, the pipeline, decision/review discipline, tone.
- `stage-idea.md` — shape a brief into a clear concept with a real hook.
- `stage-script.md` — turn the concept into a tight, runtime-budgeted spoken script.
- `stage-scene-plan.md` — break the script into timed, varied visual scenes (structured).
- `stage-assets.md` — decide what each scene needs generated; prompt discipline.
- `stage-edit.md` — sequencing, sync, captions, music ducking.
- `stage-compose.md` — render settings, pre/post-render validation, the deliverable.
- `review.md` — how to critique a stage's output before handing it off.

The content is original to this project, but the *rules* distil widely-validated
production and learning research — e.g. multimedia learning (Mayer), misconception-
first instruction (Muller), and structured multi-aspect prompting — plus hard-won
short-video pacing practice (hook in the first seconds, caption everything, duck
the music, keep something changing, fit narration to the runtime).
