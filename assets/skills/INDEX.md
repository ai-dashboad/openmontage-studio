# Agent knowledge

The production agent reads these skills to drive the pipeline. They are the
editable "how" of OpenMontage Studio — change them to change how the agent works,
no Dart edits required. This mirrors an instruction-driven design: intelligence
lives in the knowledge, the code is just plumbing.

- `production.md` — the agent's role, the pipeline, the approval contract, tone.
- `stage-idea.md` — shape a brief into a clear concept.
- `stage-script.md` — turn the concept into a tight spoken script.
- `stage-scene-plan.md` — break the script into timed visual scenes (structured).
- `stage-assets.md` — decide what each scene needs generated.
- `stage-edit.md` — sequencing, captions, music, narration decisions.
- `stage-compose.md` — render settings and the final deliverable.

All content here is original to this project.
